# 0.2.0 Release Record

**Status:** Published; all release tasks closed on 2026-09-10.

Version `0.2.0` delivers configurable routing, safe errors, saved OAuth with login/refresh/logout, persistent state and command completion. This record preserves release evidence and its limits. Current behavior is defined by the [engineering contracts](../README.md#understand-the-project), and future publications follow the [release procedure](../releases.md).

## Hosted OAuth Evidence

On 2026-09-10, the operator reported successful interactive login/logout, strategy changes and tool operation with and without authentication. They logged in for the automated check and explicitly authorized using the normal agent directory instead of an isolated directory. No credentials were copied.

The automated portion used checkout `ca1c15bdd967509a5274e1a75ccc040abff5f3bb`, Linux x64 / Node 24.21.0, Pi 0.85.1 and MCP SDK 2.0.0. `EXA_API_KEY` was unset and `PI_EXA_WEB_LIVE_TEST=1` was set.

| Check | Result |
| --- | --- |
| Saved credentials | Access token and refresh token present; values not recorded |
| OAuth search | Registered command selected `authenticated-first`; one search returned nonempty text with `details.auth: oauth`, no fallback and no refresh |
| Local expiry override | After process shutdown, a separate process used the production revision-checked transaction to set only `expiresAt` to local time minus one second; credentials were otherwise preserved |
| Fresh-process refresh and fetch | Exactly one `refresh_token` grant request and successful HTTP response; committed revision advanced, credentials became locally usable and retained a refresh token; one fetch returned nonempty text with `details.auth: oauth` and no fallback |
| Cleanup | Registered status/logout handlers completed, saved credentials became null, and the original `anonymous-first` strategy was restored |

Pi's real extension loader loaded the checkout, and registered handlers/tools executed the operations. This establishes Hosted refresh across fresh extension-host processes; it was not a full interactive Pi restart. Interactive login is operator-reported. Total Hosted tool sends were two, without retries or deliberate rejection. No coordination database was deleted.

No token values, authorization material, queries, fetched URLs, result text or network dumps are retained here. Manual TUI completion testing was not recorded. Local fixtures verify transaction and failure behavior independently of Hosted availability.
